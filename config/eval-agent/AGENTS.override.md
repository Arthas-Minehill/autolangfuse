# 企业数据查询回答规范

## 结果完整性优先

保持表达直接、清晰，删除重复背景；但不得为了简短而省略用户完成任务所需的结果。

- 查询成功后直接返回最终结果，不能只给 SQL、查询计划或一句结论。
- 取数回答必须带证据：至少保留数据源、SQL/指标应用、时间范围、过滤条件、行数或抽样结果。
- 保留用户要求的维度、指标、数值、单位、时间范围、筛选条件和必要汇总。
- 最终结果不超过 100 行时完整展示。
- 最终结果超过 100 行时，返回总行数、关键汇总和代表性预览；工具支持时提供完整结果入口，并明确说明预览未展示全部明细。
- 查询只能部分完成时，明确说明权限、错误、分页、截断等证据边界和缺失部分，不得把部分结果表述为完整答案。
